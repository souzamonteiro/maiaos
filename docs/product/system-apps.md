# MaiaOS system application catalog

System programs should be `.wasm` wherever practical; native firmware is reserved for boot/recovery, device drivers and privileged host services. Each application should have a desktop acceptance test and a Tab5 acceptance test.

| ID | Program | Role | Priority | Planned source and toolchain |
|---|---|---|---|---|
| `init` | System Init | Load policy and start essential services | P0 | C++98 via MaiaCpp -> MaiaC -> WASM |
| `io` | Maia I/O | TTY, terminal streams and asynchronous input/output | P0 | Planned C++98 guest via MaiaCpp |
| `shell` | Maia Shell | Command parser and execution | P0 | Planned C++98 guest via MaiaCpp; grammar parser generated by MaiaCC |
| `desktop` | Maia Desktop | Graphical session, launcher and window management | P0 | Planned C++98 guest via MaiaCpp |
| `terminal` | Maia Terminal | Text I/O, logs and developer tools | P0 | C++98 guest via MaiaCpp; I/O through MaiaOS ABI |
| `files` | Maia Files | Browse VFS, copy, move and delete | P1 | Maia Suite WASM toolchain |
| `settings` | Maia Settings | Display, storage, device and app settings | P1 | Maia Suite WASM toolchain |
| `monitor` | Maia Monitor | CPU, memory, instances, filesystem and uptime | P1 | Maia Suite WASM toolchain |
| `installer` | Maia Package Manager | Install and verify app packages | P1 | Maia Suite WASM toolchain |
| `editor` | Maia Text Editor | Edit text/config files | P2 | Maia Suite WASM toolchain |
| `console` | Maia Developer Console | Inspect WASM modules and ABI traces | P2 | Maia Suite WASM toolchain |
| `clock` | Maia Clock | Monotonic uptime and app lifecycle reference | P0 | Implemented: C++98 via MaiaCpp -> MaiaC -> WASM |
| `calculator` | Maia Calculator | Runnable LVGL/WASM reference app | P0 | Implemented: C++98 via MaiaCpp -> MaiaC -> WASM |
| `viewer` | Maia Media Viewer | Image viewing within memory limits | P3 | Maia Suite WASM toolchain |
| `network` | Maia Network | Connection diagnostics via available device transport | P2 | Maia Suite WASM toolchain |
| `update` | Maia Update | Verified firmware/system app update workflow | P2 | Maia Suite WASM toolchain |

The target boot artifact sequence is the unchanged Espressif ROM/second-stage bootloader, a MaiaOS platform boot host, then `kernel.wasm`, followed by the planned `io.wasm`, `shell.wasm` and `desktop.wasm` services/guests. Only the kernel, Calculator and Clock guests currently exist. In this table, “Maia Suite WASM toolchain” does not claim that the listed application is implemented.

Toolchain policy: C++98 guests use MaiaCpp AST-strict to generate C89, then MaiaC and MaiaWASM produce/validate WASM. MaiaCC generates parsers from EBNF. Emscripten is used only for the LVGL-WASM browser platform module, not for OS guests.

## Native services

- Boot coordinator and recovery UI
- MaiaWASM runtime
- Host ABI dispatcher and capability manager
- MaiaGFX UI task, input router, resource manager
- MaiaVFS filesystem adapters
- MaiaEvents event queues and timers
- MaiaProcess instance manager and scheduler
- MaiaIPC bounded message queues
- MaiaDevices HAL and device diagnostics
- Logging, crash reports and update verification

## MVP user experience

Power on -> MaiaOS splash -> launcher -> Calculator + Terminal + Monitor. Opening a WASM application creates a window, responds to touch and can be terminated without rebooting the device.
